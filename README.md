Learning how to prepare raw data before using it for Machine Learning.

Topics include:

- Loading datasets
- Understanding datasets
- Handling missing values
- Removing unnecessary data
- Handling duplicate values
- Encoding categorical data
- Feature scaling
- Normalization
- Standardization
- Splitting data into training and testing sets

Understanding and analyzing datasets before building Machine Learning models.

Topics include:

- Understanding data
- Descriptive statistics
- Data distribution
- Correlation
- Outlier detection
- Data visualization
- Histograms
- Scatter plots
- Box plots
- Correlation heatmaps

Topics include:

- Regression evaluation

### 5. Classification

Learning algorithms used to classify data into different categories.

Topics include:

- R² Score

### 8. Feature Engineering

- Feature extraction
- Feature transformation
